# Ma bibliothèque — exercice CSS

Ouvrir `index.html` avec Live Server.

- `index.html` : catalogue HTML d'origine avec trois livres.
- `book.html` : fiche HTML de Moby-Dick conservée.
- `style.css` : CSS commun volontairement minimal (reset, variables, Flexbox, Grid, focus et responsive).
- `book.css` : styles simples réservés à la fiche.
- `motion.js` : le titre d'accueil se déplace horizontalement.
- `assets/images/moby-dick.svg` : couverture locale.

La recherche et la commande restent des maquettes, comme prévu par les exercices. Le mouvement JS est le seul ajout fonctionnel demandé ; pas d'autre JavaScript de navigation ou de recherche.
